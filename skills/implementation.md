# Skill: implementação

## Objetivo

Realizar mudanças precisas que atendam ao requisito sem alterar comportamento não relacionado.

## Processo

1. Converta os critérios de conclusão em casos observáveis, incluindo casos de borda relevantes.
2. Escolha os pontos de alteração menores que cubram esses casos sem duplicar lógica.
3. Siga os padrões e APIs existentes; prefira dependências já disponíveis.
4. Adicione ou ajuste testes focados no comportamento solicitado.
5. Revise o diff para remover alterações incidentais e verificar compatibilidade.

## Resultado

Uma alteração limitada ao escopo, testes pertinentes e um resumo das verificações executadas e pendentes. Se os requisitos não forem claros o bastante para escolher um comportamento correto, peça esclarecimento antes de codificar.
